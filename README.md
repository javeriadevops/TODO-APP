# 📝 To-Do List App (Streamlit)

A simple and stylish **To-Do List** built with **Python & Streamlit**.  
Users can add tasks, mark them as completed, and delete them easily.  

## 🚀 Features
- Add new tasks
- Mark tasks as done ✅
- Delete tasks 🗑️
- Clean and colorful UI  

## 🖥️ Run Locally
```bash
streamlit run todo_app.py
